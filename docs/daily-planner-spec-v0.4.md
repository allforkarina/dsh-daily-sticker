# DSH Daily Learning — 每日任务备忘录

版本：0.4-scope-review  
日期：2026-10-09  
状态：用户已于 2026-10-09 确认，按本精简范围实施。

## 1. 目标与权威

做一个 DeepSeek Harness 插件：每天规划今日学习任务，在类似备忘录的面板中展示，方便用户复制到其他 Agent 工具中完成学习。

用户在外部工具中学习、导出 Markdown 聊天记录，再自行交给 DSH notebook 助手整理笔记。这是用户的学习流程，本插件不导入聊天、不调用 notebook、不承担笔记总结。

用户于 2026-10-09 明确纠正并确认：不需要文本进度回填，也不需要任务步骤勾选；不要扩展成复杂学习管理系统。本稿优先于旧实施计划及重建 v0.3 spec。旧文档保留为历史参考，不能继续把复杂管理条款视为本版必须实现。

## 2. 已确定的任务方向

| 类别 | 预算 | 默认规划方向 |
| --- | --- | --- |
| 算法 | 30 分钟 | 合适的真实 LeetCode Easy/Medium 题，给官网链接及练习方向。 |
| LLM | 30 分钟 | 原理与实践：Prompt → token → embedding → Attention → Transformer → 训练与微调 → 对齐 → 推理；按预算拆成小主题。 |
| Agent 工程 | 60–120 分钟 | 未提供项目时先按大类给概要，如实现工具调用；提供具体项目后围绕完善该项目安排每日任务。 |
| AI 探索 | 约 25 分钟 | 实用与研究兼顾，每日一个主主题，必要时提供最多两个备选。 |

各类别独立预算，不限制总量，不强制计时。首版一个当前工程项目，可更换，旧计划保留原项目背景。

## 3. 面板与操作

左栏固定入口，打开全局备忘录式主面板，与会话及 Workspace 无关。

面板上方显示日期与准备状态，下方按四类显示今日任务。主视图内容以概要为主：主题、预计时间、简要安排及资料链接；需要时展开具体建议，复制到外部工具开展学习。

保留原计划中的简单任务完成勾选，勾选整个任务即可；不要求填写任何学习记录、理解状态、用时或步骤。

必要操作为准备/明确重新规划、复制任务、复制学习 Prompt、完成勾选与查看已保存日期。设置仅提供规划所需背景和偏好，不建设管理仪表盘。四类角色以文本预设参与复制 Prompt，不启动 Agent。

不实现任务步骤进度、理解评测、路线掌握状态、复杂续学队列、冻结打卡统计、学习记录编辑器或专门的项目管理功能。路线只辅助选下一主题，不作为学习评测系统。日期保存用于恢复计划及提供规划上下文，不把过去任务是否完成推断成用户知识是否掌握。

## 4. 每日准备与可靠性

autoPrepareOnOpen 默认开启，可关闭。进入尚未准备的今日面板时自动准备；已有今日计划直接恢复。只有明确重新规划才替换已有规划，不因焦点切回、刷新、午夜或后台启动重复调用模型。

不补建缺席日期。未配置模型时提供模板；来源失败显示实际缺失或缓存时间，不编造题目、资讯、发布日期或验证状态。

算法使用可验证的题源，Hard 或未知难度回退 Easy/Medium 题池；无可用题源标待选题。AI 探索尽量读取原始来源，检索近 7 天、必要时扩展至 30 天，发布时间未知时不声称近期。

项目背景由用户填写或提供明确的公开资料，不读取或执行本地工程。切换项目不覆写已保存计划；之后生成的工程任务围绕新项目。

日期计划保存到用户选择的本地 dataRoot，保留 JSON/Markdown，重启恢复。实现保证已提交计划不因普通重启丢失；保存失败给明确错误，不显示成功。保留基本原子写入及并发保护，不建设通用迁移或事件溯源平台。

## 5. 宿主接入与交付

名称统一为 dsh-daily-learning。使用 sidebar.panellist + main，同 id；Host ESM、Client lazy-CJS，与 DSH 正式 slot/loader 协议兼容。

规划调用使用宿主 ctx.llm 与已配置模型，资料优先通过 ctx.web。插件不采集或另存 API Key。环境配置通过正式宿主配置入口保存，目录或模型未配置也能加载本插件。

Host/Client 通信复用宿主认证，限制请求动作、正文与输入；不能因简化产品而开放任意文件或未认证写接口。集成与依赖以本机 DSH 0.2.0-rc.2 实际安装核实，不凭旧报告宣称已通过运行验收。

交付可上传 GitHub 的源码、构建脚本、预构建包、安装说明和实际验证结果。不上线、不替用户公开发布、不改现有生产 profile。开发验证使用隔离测试环境。

## 6. 精简验收

1. 目标 DSH 中可从左栏打开无会话的备忘录面板。
2. 每日显示四类任务，符合已确定方向与各类时间预算。
3. 配置模型后实际规划可用；无模型或来源失败有明确模板/降级。
4. 复制任务/Prompt 与简单完成勾选可用，无回填门槛。
5. 同日刷新与重启恢复已保存计划，不重复规划；跨日用户进入才准备新日。
6. 项目背景影响后续工程规划，旧日期内容不自动覆写。
7. 日期 JSON/Markdown 保存可用，失败不伪装成功；卸载保留业务数据。
8. 预构建包可安装，Host/Client 均实际加载；未验证环境如实注明。
