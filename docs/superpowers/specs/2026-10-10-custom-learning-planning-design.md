# 自定义每日学习规划 — 0.2.0 设计

状态：待用户确认。依据：用户选择自由文本配置，由用户手动维护当前阶段。

## 目标

在现有每日任务备忘录中，允许分别配置算法、LLM、Agent 工程和 AI 探索的学习路径、当前阶段、近期目标和内容倾向，并用于生成实际任务和复制学习 Prompt。继续使用现有时间预算、完成勾选和本地日期保存。

## 设置

新增“各类学习规划”区域，每类提供四个可选文本框：

- 学习路径：可以粘贴有顺序的课程、主题或长期规划。
- 当前阶段：当前学习位置、已有基础或希望从哪里开始。
- 近期目标：接下来希望完成的学习或实践目标。
- 内容倾向：理论/实践偏好、关注方向及希望避免的内容。

各字段可留空。用户手动修改当前阶段，任务完成勾选不自动推进章节。角色风格保持独立；现有工程项目、AI 兴趣、预算和内置 LLM 起点保留。

## 生成规则

自定义学习规划优先于内置路线和默认兴趣。留空的部分继续使用现有默认规则。当前工程项目仍用于约束工程任务的实际场景；若学习路径与项目无法兼顾，给出适合当前阶段的最小任务，不能假定用户已学完前置内容。

LLM 和 Agent 的内置主题是未自定义时的后备路线，不能要求模型继续遵循与自定义规划矛盾的内置主题。近期计划只提供上下文，已勾选任务不等于掌握整个章节。

算法规划应影响真实题目的选择与练习方向；只能引用已验证的 LeetCode Easy/Medium 题。无法获取符合方向的真实题目时应说明限制，不编造题目或声称已匹配。

AI 探索的自定义规划还用于调整资讯检索方向，避免只改变模型提示词而仍检索旧兴趣。继续核验来源、正文及时间；无可用资料时提供明确的非时效练习，不能伪造近期资讯。缓存随相关规划改变而区分。

复制学习 Prompt 时包含对应类别的角色风格和学习规划，以及实际任务，使外部学习工具获得同样的上下文。

## 生效与兼容

保存设置后用于下一次任务生成。已有今日计划不自动覆写；用户点击“重新规划未完成项”即可应用新设置，已完成任务保留。界面明确提示该行为。

未配置模型或模型失败时仍使用模板，明确提示自定义自由文本尚未被模型展开，不承诺模板能理解任意学习路径。

旧版偏好缺少新字段时补充空默认值，保留旧目录、历史计划、角色风格和勾选状态。保存设置仍遵循现有版本冲突保护。合理限制文本和请求大小，确保中文规划可正常保存。

## 验证与发布

验证旧数据升级、各类配置保存及重启恢复、配置参与生成与检索、默认路线回退、复制 Prompt、明确重规划及已完成项保留。使用本机 DSH 预览版的隔离环境验证实际面板，不修改用户生产数据。

构建并检查发布包，版本提升为 dsh-daily-learning@0.2.0，更新安装和配置说明，推送现有 GitHub 仓库并发布 npm 官方源。验证官方源可获取新版本及 DSH 安装路径。若 npm 要求设备认证，由用户在设备完成认证，不收集密码、验证码或 token。

不新增学习记录回填、章节进度管理、聊天导入、笔记总结或自动评测。
